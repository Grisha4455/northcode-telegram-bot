# NorthCode — Telegram-бот для приёма заявок веб-студии

Бот принимает заявки на разработку сайтов прямо в Telegram: задаёт клиенту 6 вопросов о проекте и отправляет готовую заявку администратору.

## Возможности

- Приветствие с кнопками «Оставить заявку» и «Подробнее» (inline-клавиатура)
- Пошаговый опрос из 6 вопросов: тип проекта, описание, примеры, сроки, бюджет, контакты
- Выбор типа проекта кнопками: интернет-магазин, лендинг, корпоративный сайт, веб-приложение, редизайн
- Готовая заявка с датой и данными клиента уходит в чат администратора
- Поддержка прокси через переменные окружения

## Стек

- Python 3, [python-telegram-bot 20](https://python-telegram-bot.org/) (async, `ConversationHandler`)
- python-dotenv для настроек

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # впишите токен бота и ID чата администратора
python bot.py
```

Токен выдаёт [@BotFather](https://t.me/BotFather). Файл `.env` не попадает в репозиторий: он указан в `.gitignore`.

## Структура

```
bot.py           — логика бота и сценарий опроса
config.py        — тексты и настройки, чтение переменных окружения
.env.example     — шаблон настроек
requirements.txt — зависимости
```
